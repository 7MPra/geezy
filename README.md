# Geezy

Wii Homebrew用のVJビデオシンセ。0.4は、漆黒・純白・ネオンの巨大構造を常時高速で貫通する試作です。音同期は行いません。

## 起動・操作

```powershell
./scripts/run.ps1
```

既定のDolphinは `D:\Dolphin-x64\Dolphin.exe`。別の場所なら `-Dolphin 'パス'`。実行ファイルは `apps/geezy/boot.dol`。専用プロファイル `.dolphin-prototype` を使用します。初回の画面設定はウィンドウに引き伸ばす設定です。既存のGFX.iniは上書きしません。

Wiiリモコンは十字キーが左になる横持ち。センサーバー不要。Dolphinでは映像ウィンドウにフォーカスを置いて操作してください。

| 操作 | Wiiリモコン | Dolphinキーボード |
| --- | --- | --- |
| 打撃・高速貫通・カメラジャンプ | Aを押す | A |
| 5fps・低速巡航＋スリット幅を拡張 | Aを長押し | Aを長押し |
| 打撃＋領域反転。長押しでマスクを維持 | B | B |
| パレット再生成＋反射帯の周波数切替＋打撃 | 1 | 1 |
| リング／巨大十字柱／スパイク／リボンを切替 | 2 | 2 |
| X/Y方向を変更して斜め前方へ突進、残像をねじる | 横持ちの十字キー | 矢印キー |
| 35度望遠／135度超広角へジャンプ | ＋／− | E／Q |
| 復帰：物理・色・カメラ・残像を初期化 | ＋と−を同時押し | R |
| 特大打撃（通常の2.5倍） | シェイク | Dolphinの加速度エミュレーション設定から |
| 終了 | HOME | H |

無入力でも通常135 unit/secで巡航します。Aでさらに突進し、長押しで25 unit/sec・5fpsへ落とす。Bで反転、2で空間を切り替え、Rで基準状態に戻せます。シェイクは任意の強いアクセントです。

## 描画と運動

- Clear Colorと複数のパレット帯はRGB(0,0,0)、ハイライトはRGB(255,255,255)。色帯は最小成分0・最大成分255へ正規化。黒は意図した描画色です。
- 64×64共有環境マップは4／6／8階調。1で周波数2.5→6.0→12.0→2.5と巡回。REPEAT・最近傍補間で描画します。
- ドーム・巨大構造・破片の約1/3は頂点カラー0の漆黒。全面の下敷きクワッドは廃止し、内向きドームが空間を包みます。
- EFBのRGB565コピーを3本の水平／垂直スリットへ不透明100%で描画。1.03〜1.08倍のズーム・回転・UVオフセットを加えます。半透明合成による中間色は作りません。A長押しでスリット幅を広げます。
- 60Hz固定物理で、通常135／slow時25 unit/secの巡航に減衰する入力インパルスを加算。基礎回転とUVスクロールも継続します。
- 20tickごとに小さな速度・回転バースト、ロール角のステップ、UVジャンプを自律的に追加します。
- 描画用のカメラ・頂点・UVは通常4tickごとの15fps、A長押し中12tickごとの5fpsで更新。打撃の最初のジャンプは次の描画で即反映します。
- シェイクはlibogcの校正済みGForceを使用。正常な加速度レポートで |g|−1 が0.65gを超えると2.5倍の打撃。10物理tick（約167ms）のクールダウンと、0.3g未満への復帰による再検出を行います。
- 96単位のカメラ基準モジュロで4空間と192枚の破片を循環配置。手前の巨大面、FOV・ロール・投影中心のジャンプを重ねます。
- 3Dの後にブラインド／チェッカー／十字／斜め分割で `GX_LO_INV` による領域反転を適用します。

## ビルド・検証

Docker Desktopを起動してから：

```powershell
./scripts/build.ps1
./scripts/check-render.ps1
```

buildは巡航、15／5fpsサンプリング、自律バースト、シェイクの強度・閾値・クールダウン・再検出、フレームレート独立性、モジュロ境界、連打、周波数巡回と復帰のassertテストを実行してビルドします。

check-renderは別バイナリと `.dolphin-check` で4空間・打撃・合成加速度によるシェイク・低速巡航・反転を自動切替。キーやフォーカス操作を行わず、ウィンドウ単独の16枚の画像を `artifacts/render-*.png` へ保存します。黒・白・高彩度色の存在と画像の変化を検査し、黒を失敗扱いにはしません。通常版に自動操作は入りません。

WiiではSDカードの `apps/geezy` に `boot.dol` と `meta.xml` をコピーしてHomebrew Channelから起動します。実機性能・実リモコンのシェイク感度・出力変換器は未確認。映像モードは本体設定に従います。長時間停止後の物理追従は0.25秒までです。

Makefileは[devkitPro公式Wiiサンプル](https://github.com/devkitPro/wii-examples/tree/master/graphics/gx/triangle)がベース。描画と加速度入力は[libogc](https://github.com/devkitPro/libogc)を使用しています。
