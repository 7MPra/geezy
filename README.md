# Geezy

Wii Homebrew用のVJビデオシンセ。0.10.0は、ボタンだけで漆黒の浮遊空間から全画面の極彩色まで演奏する試作です。音同期は行いません。

## 起動・操作

```powershell
./scripts/run.ps1
```

既定のDolphinは `D:\Dolphin-x64\Dolphin.exe`。別の場所なら `-Dolphin 'パス'`。実行ファイルは `apps/geezy/boot.dol`。専用プロファイル `.dolphin-prototype` を使用します。初回の画面設定はウィンドウに引き伸ばす設定です。既存のGFX.iniは上書きしません。

Wiiリモコンは十字キーが左になる横持ち。センサーバー不要。Dolphinでは映像ウィンドウにフォーカスを置いて操作してください。

| 操作 | Wiiリモコン | Dolphinキーボード |
| --- | --- | --- |
| 2秒チャージ＋空間圧縮、離すと1.2〜4倍の打撃 | Aを長押し→離す | A |
| 全画面支配＋開閉する反転マスク | B | B |
| 反射色切替＋打撃（離した時に確定） | 1を押して離す | 1 |
| 主役の編成と進行軌道を同時切替＋打撃（離した時に確定） | 2を押して離す | 2 |
| タップで方向転換＋打撃、長押しで5倍ブースト＋視線をずらす | 横持ちの十字キー | 矢印キー |
| 主役から大きく視線を外す（離すと復帰） | B＋十字キー | B＋矢印キー |
| 速度・密度の4段ギアを上げる／下げる | ＋／− | E／Q |
| 復帰：物理・色・カメラ・チャージを初期化 | ＋と−を同時押し | R |
| 特大打撃（任意・通常の2.5倍） | シェイク | Dolphinの加速度エミュレーション設定から |
| 終了 | HOME | H |

最初はギア1。−で静かなギア0、＋を2回押すと最大のギア3です。十字キーを短く押して方向を打ち込み、長押しで加速。Aで空間を引っ掛け、離して解放。Bを押すとギアに関係なく全画面支配と反転グラフィックが立ち上がり、離すと収束します。シェイクなしで全操作が完結します。

## コマンドで見た目を組み合わせる

方向は横持ちした時の上下左右。Dolphinでは数字キー・A/Bと矢印キーの組み合わせです。1・2の単押しは離した時に確定し、コマンドに使った場合は単押しの色／編成変更を発火しません。コマンドを押しっぱなしにしても連打されません。

| 同時押し | ↑ | → | ↓ | ← |
| --- | --- | --- | --- | --- |
| **1＋方向：主役の質感** | クローム | 発光グリッド | 走査線ゴースト | 単色ネオン |
| **2＋方向：主役の配置** | 非対称トリニティ | 縦積み | 横並び | 奥行き列 |
| **1＋2＋方向：背景** | 格子＋トンネル | 小ポリゴントンネルのみ | 格子のみ | 小ポリゴンの3Dマトリクス |

| 同時押し | 動作 |
| --- | --- |
| **A＋1** | 反射模様をホライゾン→4階調→オイルスリック→白黒へ巡回 |
| **A＋2** | 主役の編成だけを5種類で巡回（進行軌道を維持） |
| **B＋1** | 反転図形をブラインド→チェッカー→十字→三角形→同心角枠→放射ウェッジへ巡回 |
| **B＋2** | 進行軌道だけをStraight→Spiral→Grid→Whipへ巡回（主役を維持） |
| **1＋2を押し、両方離す** | リミックス：編成・配置・質感・背景・反射・軌道・図形・色をまとめて組み直す |

例えば「1＋→で発光グリッド」「2＋↓で横並び」「1＋2＋←で粒子マトリクス」を順番に打ち込み、Aを溜めながら2で編成を入れ替え、離してドロップできます。各設定は次のコマンドまで保持され、リミックスも速度ギアを維持します。反射模様はクローム／ゴーストで見え、グリッドと単色ネオンは専用の色表現を使います。

A/Bはコマンド中もチャージ／アクセントとして動作します。Aを先に押して1や2を叩けば、溜めを継続したまま切り替えられます。1・2を使う方向コマンド中は操舵とブーストを抑制し、B＋方向の視線外しと区別します。斜め方向は設定を選びません。複数の指定が重なった場合は「方向コマンド→Bの組み合わせ→Aの組み合わせ」の順に優先します。1＋2に方向を加えるとリミックス予約は取り消されます。

四隅のUIに現在の設定番号を表示：S＝編成、L＝配置、M＝質感、V＝軌道、BG＝背景、R＝反射、X＝反転図形（いずれも0始まり）。装飾文字は追加しません。＋と−の同時押しで全設定を初期化できます。

## 描画と運動

主役と背景を別の座標系で描きます。主役3体はローカルな非対称アンカーに常駐し、進行座標 `world_cam` は背景だけを移動させます。方向を変えて走り続けても主役は遠方へ流されません。

- **A / クローム**：128×128、LINEAR、CLAMP。曲率補正したnyの−0.28〜0未満は漆黒、0〜0.14は純白。上側は白→ネオン→天頂の黒へ滑らかに移り、下側は−0.65付近の1本だけが別色相で反射します。トーラスは頂点の滑らかな法線を回転・ビュー変換し、環境マップを引きます。TEVは1段、ディザなし。ホライゾン設定では1を4回押すごとに虹色のオイルスリックになります。
- **B / グリッド**：64×64＋1×1までのミップマップ、トライリニア＋4倍異方性フィルタ、REPEAT。黒い面の縁と中央線だけが発光し、UVが一方向へ流れます。
- **C / ケージ**：テクスチャを使わない純白またはシアンの線と頂点ドット。八面体の外側で二重のケージが逆回転します。
- **D / 黒とゴースト**：反射しない黒い面、またはTEV 2段で8×8走査線を乗算するゴースト。クロームとの対比に使います。

2で「トーラス＋ケージ付き八面体＋スパイク」「3連ジャイロ」「八面体＋スパイク衛星」「スパイク中心の混成」「二重角フレーム＋ジャイロ＋ケージ」の5編成を切り替えます。装飾文字は2D・3Dとも撤去し、文字は四隅の計器だけに限定。形状は剛体で、八面体の頂点のみ打撃で放射状に伸びます。アンカーの位置交換はイージングします。

背景は24単位間隔の連続した長い格子梁。192単位の描画範囲でX/Y/Zすべてを循環させ、視点から60〜84単位で黒へ減衰するため、再配置される遠端は見えません。主役周囲20単位は梁の該当区間だけを切り取り、20〜32単位で徐々に立ち上げます。セル丸ごとの突然の消去、重複する端面、遠景の高周波ゴースト模様は撤去。通常時は背景の移動とUVを60Hz、主役の姿勢は20fpsのまま更新します。A中は背景も8tickのチャージ動作に従います。

小ポリゴン192個をリング状に配置したトンネル層を格子に重ねます。各片はワールドに固定され、3軸とも96単位で循環。視点から32〜44単位で消え切ってから再配置し、主役の周囲12〜18単位も減衰させます。実際の移動方向へ片を伸ばし、加速時に長くなる軌跡で進行ベクトルを見せます。

カメラは `guLookAt` と球面オービットを使用。打撃ごとに主役0→1→2→重心の注視を切り替え、注視点は係数0.42で先に動き、方位・仰角・ロールは最短角度差を使う `vel = vel*0.55 + delta*0.16` のスプリングで追従します。バンクと打撃由来のロール目標、およびburstは0.86で減衰し、余韻を残します。十字キーでバンクし、画面方向へ視線をずらします。B＋十字キーでは大きく狙いを外せます。オービット中心と実際の注視先を分離しているため、主役を画面外へ送るパンが可能。離すと視線は主役へ戻ります。微細なリサージュの呼吸を加えます。距離は基準FOV80度・基準距離16から `k = 16*tan(80°/2)` を作り、常に `radius = k/tan(FOV/2)` で逆算。フレーミング用の距離補正は使いません。中央注視時に保存されるのは注視点の奥行きでの投影倍率です。視線外し中は意図的に構図を崩します。別の奥行きにある衛星や長いスパイクは広角・個別注視時に画面端を横切る場合があります。

- ギア0〜3の巡航速度は3／12／36／72 unit/sec。十字キー長押しで1→5倍ブースト、離すと指数減衰で復帰。主役の基礎回転も巡航速度×ブーストに連動し、打撃の回転インパルスを加算します。角度の循環周期は各回転軸の速度比に合わせ、折り返しによる姿勢ジャンプを防ぎます。
- 進行軌道はStraight／Spiral／Grid／Whip。Gridは6tickごとに一軸のみ、最大24単位のステップ。
- 60Hz固定物理、通常3tickごとの20fps姿勢更新。インパルスは600×強度、毎tick0.85の減衰。
- Aは2秒でtensionが0→1。8tickごとに描画姿勢を更新し、FOV80→38度・アンカー圧縮・頂点グリッド吸着。高チャージで微振動と背景UVの高速流動。解放で1.2〜4倍の打撃、FOV125度・overdrive最大、その後収束。
- burst>0.5またはtension>0.3で3D画面をEFBに取得し、赤・青を逆方向へずらして緑と再合成。アルファ残像を使わず、UIを巻き込みません。
- 開閉イージング付きの2D反転図形（ブラインド・チェッカー・十字・三角形・同心角枠・放射ウェッジ）と、四隅のVEL／GEAR／FOV／SEED／TNS計器を維持。TNSは0.7を超えると点滅します。
- 任意のシェイクは校正済みGForceの |g|−1>0.65gで2.5倍打撃。10tickクールダウンと0.3g未満への復帰で再検出します。

## ビルド・検証

Docker Desktopを起動してから：

```powershell
./scripts/build.ps1
./scripts/check-render.ps1
```

buildは単押しと同時押しの分離・順序違い・押しっぱなしでの多重発火防止・256回のリミックスとリセット、およびassertテスト（4段ギア、ブーストの立ち上がりと復帰、overdrive、4種の軌道とGridの単軸制約、Aの8tick更新・2秒チャージ・単発解放と強度差、安全なフォント参照・5種類の構造巡回、主役とワールド進行の分離、3軸モジュロ周期、指定バネ係数・最短角度・オーバーシュートと収束、nyプロファイルの黒白帯・単一反射リング、注視追従・ドリーズーム・連打時のリグ安定性、頂点吸着、マスクの開閉、目標追従、シェイク、フレームレート独立性、連打・復帰）を実行してWii向けにビルドします。

check-renderは別バイナリと `.dolphin-check` でギア・軌道・方向入力・Aのホールドと解放・質感／配置／背景の方向コマンド・反射模様4種・図形マスク6種・B＋方向の視線外しを自動切替。キーやフォーカス操作なしで26枚を `artifacts/render-*.png` に保存し、黒・白・高彩度色の存在と画像の変化を検査します。通常版に自動操作は入りません。 `./scripts/check-render.ps1 -Lattice` は背景だけを3軸へ連続移動させ、64枚の連続画像を保存し、背景の消失と大きな占有率ジャンプを検査します。ユニットテストでは回転の加減速・角度折り返しの連続性・視線外しと復帰・小ポリゴンの3軸周期も検査します。再配置の前後が完全な黒になること、ワールド座標の巻き戻し前後で格子集合が一致すること、ミップマップの平均色とバッファ境界を検証します。

WiiではSDカードの `apps/geezy` に `boot.dol` と `meta.xml` をコピーしてHomebrew Channelから起動します。実機性能・実リモコンのシェイク感度・出力変換器は未確認。映像モードは本体設定に従います。長時間停止後の物理追従は0.25秒までです。

Makefileは[devkitPro公式Wiiサンプル](https://github.com/devkitPro/wii-examples/tree/master/graphics/gx/triangle)がベース。描画と加速度入力は[libogc](https://github.com/devkitPro/libogc)を使用しています。
