# Geezy

Wii Homebrew用のVJビデオシンセ。0.3は、画面を埋める巨大構造の中を入力で突進し、離散的に急停止する試作です。音同期は行いません。

## 起動・操作

```powershell
./scripts/run.ps1
```

既定のDolphinは `D:\Dolphin-x64\Dolphin.exe`。別の場所なら `-Dolphin 'パス'`。実行ファイルは `apps/geezy/boot.dol`。専用プロファイル `.dolphin-prototype` を使用します。初回作成する画面設定は「ウィンドウに引き伸ばす」で、エミュレーターの黒帯を除きます。既存のGFX.iniは上書きしません。

Wiiリモコンは十字キーが左になる横持ち。センサーバー不要。Dolphinでは映像ウィンドウにフォーカスを置いて操作してください。

| 操作 | Wiiリモコン | Dolphinキーボード |
| --- | --- | --- |
| 打撃・高速貫通・カメラジャンプ | Aを押す | A |
| 4fpsへ時間拘束＋フィードバック蓄積 | Aを長押し | Aを長押し |
| 打撃＋領域反転。長押しで反転マスクを維持 | B | B |
| 2〜4階調パレットを再生成＋打撃 | 1 | 1 |
| 4種類の空間を切替＋打撃 | 2 | 2 |
| 基準流のX/Y方向を変更して斜め前方へ突進、残像もねじる | 横持ちの十字キー | 矢印キー |
| 35度望遠へジャンプ | ＋ | E |
| 135度超広角へジャンプ | − | Q |
| 復帰：背景・物理・色・カメラ・残像を初期化 | ＋と−を同時押し | R（またはQ＋E） |
| 終了 | HOME | H |

まずAを押して突進、長押しで4fpsの余韻と蓄積、Bで領域反転、2で空間を切り替える。Rで基準状態に戻せます。全操作はボタンで完結し、シェイク検出は未実装です。

## 描画と運動

- **全面背景**：不透明なパレット模様の下地＋半径約105の内向きローポリドーム。空間的な波形をインパルスで変形し、主役と同じ環境マップを使います。Clear Colorも非黒。カメラのニアクリップでドームが欠けても下地が覆います。
- **EFBフィードバック**：前フレーム全体を1.03〜1.08倍に拡大、約2〜4度回転、UVオフセットして合成。黒へ減衰させず、新しいドーム模様と混ぜます。画面端のUVはクランプし、未描画領域を作りません。
- **固定60Hz物理**：入力で移動・回転・変形に初速を加え、1ステップごとに0.72倍へ減衰。無入力のジオメトリは停止します。フィードバックの再帰変換だけは継続します。
- **離散サンプリング**：通常は5ステップごとの12fps、A長押し中は15ステップごとの4fps。カメラと頂点の描画値をまとめて保持します。打撃の最初のジャンプはサンプル待ちをせず次の描画で反映。
- **無限配置**：カメラ基準の96単位モジュロで構造と破片を循環配置。FOVは35／135度、ロールと投影中心も入力時にジャンプします。135度は透視投影であり、光学的な魚眼歪みではありません。
- **4つの空間**：無限リングトンネル、巨大十字柱、放射状スパイク、ねじれた帯。すべてに192枚の帯／マトリクス状破片と、打撃時に画面の約半分を横切るニアクリップ直前の巨大面を重ねます。
- **2D領域反転**：3Dの後にブラインド、チェッカー、十字、斜め分割を描き、`GX_BM_LOGIC / GX_LO_INV` で背後の色を反転。打撃から7物理ステップ、またはB長押し中に有効。
- **太い反射帯**：64×64共有環境マップを2〜4階調に量子化。暗色／明色と高彩度色を使用。完全な黒・白から余裕を取り、反転で黒穴を作らない範囲にします。AAと線形補間は無効。

## ビルド・検証

Docker Desktopを起動してから：

```powershell
./scripts/build.ps1
```

ホスト側のassertテストで、停止、インパルス即応、12／4fpsサンプリング、指数減衰、フレームレート独立性、負座標を含むモジュロ境界、連打時の有限性、復帰を確認してからビルドします。

Windows上でDolphinの実描画を確認する場合：

```powershell
./scripts/check-render.ps1
```

検証専用バイナリと `.dolphin-check` を使用し、4空間・打撃・領域反転を自動で切り替えます。キーボード入力やフォーカス操作は行いません。ウィンドウ単独の16枚の画像を `artifacts/render-*.png` に保存し、RGBが完全に0のピクセルを全画素検査します。これは取得した画像の検証で、全入力組合せや実機の保証ではありません。通常版の `boot.dol` に自動操作は入りません。

WiiではSDカードの `apps/geezy` に `boot.dol` と `meta.xml` をコピーしてHomebrew Channelから起動します。実機性能・実リモコン・出力変換器は未確認。映像モードは本体設定に従います。長時間停止後の物理追従は0.25秒までに制限しています。

Makefileは[devkitPro公式Wiiサンプル](https://github.com/devkitPro/wii-examples/tree/master/graphics/gx/triangle)がベース。描画は[libogc GX API](https://github.com/devkitPro/libogc/blob/master/gc/ogc/gx.h)を使用しています。
