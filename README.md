# Geezy

Wii Homebrew用のVJビデオシンセ。0.7は、ボタンだけで漆黒の浮遊空間から全画面の極彩色まで演奏する試作です。音同期は行いません。

## 起動・操作

```powershell
./scripts/run.ps1
```

既定のDolphinは `D:\Dolphin-x64\Dolphin.exe`。別の場所なら `-Dolphin 'パス'`。実行ファイルは `apps/geezy/boot.dol`。専用プロファイル `.dolphin-prototype` を使用します。初回の画面設定はウィンドウに引き伸ばす設定です。既存のGFX.iniは上書きしません。

Wiiリモコンは十字キーが左になる横持ち。センサーバー不要。Dolphinでは映像ウィンドウにフォーカスを置いて操作してください。

| 操作 | Wiiリモコン | Dolphinキーボード |
| --- | --- | --- |
| 2秒チャージ＋空間圧縮、離すと1.2〜4倍の打撃 | Aを長押し→離す | A |
| 全画面支配＋開閉する反転マスク | B | B |
| パレット再生成＋反射帯の周波数切替＋打撃 | 1 | 1 |
| Box構造と4種の軌道を同時切替＋打撃 | 2 | 2 |
| タップで方向転換＋打撃、長押しで5倍ブースト | 横持ちの十字キー | 矢印キー |
| 速度・密度の4段ギアを上げる／下げる | ＋／− | E／Q |
| 復帰：物理・色・カメラ・チャージを初期化 | ＋と−を同時押し | R |
| 特大打撃（任意・通常の2.5倍） | シェイク | Dolphinの加速度エミュレーション設定から |
| 終了 | HOME | H |

最初はギア1。−で静かなギア0、＋を2回押すと最大のギア3です。十字キーを短く押して方向を打ち込み、長押しで加速。Aで空間を引っ掛け、離して解放。Bを押すとギアに関係なく全画面支配と反転グラフィックが立ち上がり、離すと収束します。シェイクなしで全操作が完結します。

## 描画と運動

- 黒はRGB(0,0,0)、白はRGB(255,255,255)。ネオン色は最小成分0・最大成分255。64×64共有環境マップは4／6／8階調、1で周波数2.5→6→12と巡回。REPEAT・最近傍補間です。
- ギア0〜3の基礎速度は3／12／36／72 unit/sec。十字キー長押しで倍率が1から5へ上がり、離すと指数減衰で戻ります。自動打撃はありません。
- overdriveはギアごとの0／0.18／0.72／1へ追従。Bまたはburst>1.2で1へ到達します。低密度ではドームの87.5%を省略してワイヤーのみ、高密度またはギア2以上では黒パネルを含む全周ドームを塗ります。
- TEV Stage 0でmetal×頂点色、Stage 1で8×8の白黒走査線テクスチャを高周波UVに乗算。黒は黒のままです。
- 半透明残像は廃止。burst>0.5またはtension>0.3で、UI合成前の3D画面をEFBから取得し、TEVでG／R／Bを抽出して不透明＋加算で再合成。RとBを反対へずらし、累積残像による灰色化を避けます。GXにはRGB個別の書き込みマスクがないためTEVを使用します。
- 2で構造5種（巨大ゲート／直方体リング／ジャングルジム／モノリス列／3D文字ゲート）と軌道4種（Straight／Spiral／Grid／Whip）をそれぞれ巡回。文字ゲートはHYPER・VOID・WIIの5×5グリフからBoxを構成。周囲にはギアに応じ24〜72個のBoxが循環します。
- Grid Stepは6tickごとに一軸だけ進む直角軌道。1ステップは24単位まで。他の軌道は方向ベクトルと速度に追従し、96単位の空間をカメラ基準で循環します。
- 通常は60Hz物理と3tickごとの20fps姿勢サンプリング。打撃は600×強度の初速、毎tick0.85の減衰。通常のFOV55〜105度・ロール・注視点は目標へ高速イージングします。
- Aは2秒でtensionが0→1。描画姿勢は8tick（7.5fps）ごとに更新し、FOV80→38度へ圧縮。Boxの中心を正面軸へ吸着し、0.4以上で微振動、UVを高速スクロール。全3D頂点の2/3単位グリッド吸着を維持。離すと1.2＋tension×2.8倍の打撃、FOV125度、overdrive最大となり、通常の目標FOVへ戻ります。
- 四隅にVEL／GEAR／FOV／SEEDとTNSバー・割合を反転表示。tension>0.7でバーが点滅。0–9、A–Zと記号を共通フォントで描き、未対応文字は空白になります。
- 反転マスクは `GX_LO_INV`。開く時0.3、閉じる時0.18の係数でmask_envを指数追従させ、幅やサイズを変えます。ブラインド・チェッカー・十字・三角形と、5×5文字のHYPER／VOID／ERR／WII／01／>>>を打撃ごとに巡回。文字は一文字ずつスライド／スケールします。
- 任意のシェイクは校正済みGForceの |g|−1>0.65gで2.5倍打撃。10tickクールダウンと0.3g未満への復帰で再検出します。

## ビルド・検証

Docker Desktopを起動してから：

```powershell
./scripts/build.ps1
./scripts/check-render.ps1
```

buildはassertテスト（4段ギア、ブーストの立ち上がりと復帰、overdrive、4種の軌道とGridの単軸制約、Aの8tick更新・2秒チャージ・単発解放と強度差、安全なフォント参照・5種類の構造巡回、頂点吸着、マスクの開閉、目標追従、シェイク、フレームレート独立性、連打・復帰）を実行してWii向けにビルドします。

check-renderは別バイナリと `.dolphin-check` でギア・軌道・方向入力・Aのホールドと解放・Bの文字マスク6種を自動切替。キーやフォーカス操作なしで26枚を `artifacts/render-*.png` に保存し、黒・白・高彩度色の存在と画像の変化を検査します。通常版に自動操作は入りません。

WiiではSDカードの `apps/geezy` に `boot.dol` と `meta.xml` をコピーしてHomebrew Channelから起動します。実機性能・実リモコンのシェイク感度・出力変換器は未確認。映像モードは本体設定に従います。長時間停止後の物理追従は0.25秒までです。

Makefileは[devkitPro公式Wiiサンプル](https://github.com/devkitPro/wii-examples/tree/master/graphics/gx/triangle)がベース。描画と加速度入力は[libogc](https://github.com/devkitPro/libogc)を使用しています。
