# Geezy

Wii Homebrew用のVJビデオシンセ。0.8.2は、ボタンだけで漆黒の浮遊空間から全画面の極彩色まで演奏する試作です。音同期は行いません。

## 起動・操作

```powershell
./scripts/run.ps1
```

既定のDolphinは `D:\Dolphin-x64\Dolphin.exe`。別の場所なら `-Dolphin 'パス'`。実行ファイルは `apps/geezy/boot.dol`。専用プロファイル `.dolphin-prototype` を使用します。初回の画面設定はウィンドウに引き伸ばす設定です。既存のGFX.iniは上書きしません。

Wiiリモコンは十字キーが左になる横持ち。センサーバー不要。Dolphinでは映像ウィンドウにフォーカスを置いて操作してください。

| 操作 | Wiiリモコン | Dolphinキーボード |
| --- | --- | --- |
| 2秒チャージ＋空間圧縮、離すと1.2〜4倍の打撃 | Aを長押し→離す | A |
| 全画面支配＋開閉する反転マスク | B | B |
| 反射色切替（4回ごとにオイルスリック）＋打撃 | 1 | 1 |
| 主役の編成と4種の進行軌道を同時切替＋打撃 | 2 | 2 |
| タップで方向転換＋打撃、長押しで5倍ブースト | 横持ちの十字キー | 矢印キー |
| 速度・密度の4段ギアを上げる／下げる | ＋／− | E／Q |
| 復帰：物理・色・カメラ・チャージを初期化 | ＋と−を同時押し | R |
| 特大打撃（任意・通常の2.5倍） | シェイク | Dolphinの加速度エミュレーション設定から |
| 終了 | HOME | H |

最初はギア1。−で静かなギア0、＋を2回押すと最大のギア3です。十字キーを短く押して方向を打ち込み、長押しで加速。Aで空間を引っ掛け、離して解放。Bを押すとギアに関係なく全画面支配と反転グラフィックが立ち上がり、離すと収束します。シェイクなしで全操作が完結します。

## 描画と運動

主役と背景を別の座標系で描きます。主役3体はローカルな非対称アンカーに常駐し、進行座標 `world_cam` は背景だけを移動させます。方向を変えて走り続けても主役は遠方へ流されません。

- **A / クローム**：128×128、LINEAR、CLAMP。曲率補正したnyの−0.28〜0未満は漆黒、0〜0.14は純白。上側は白→ネオン→天頂の黒へ滑らかに移り、下側は−0.65付近の1本だけが別色相で反射します。トーラスは頂点の滑らかな法線を回転・ビュー変換し、環境マップを引きます。TEVは1段、ディザなし。1を4回押すごとに虹色のオイルスリックになります。
- **B / グリッド**：64×64＋1×1までのミップマップ、トライリニア＋4倍異方性フィルタ、REPEAT。黒い面の縁と中央線だけが発光し、UVが一方向へ流れます。
- **C / ケージ**：テクスチャを使わない純白またはシアンの線と頂点ドット。八面体の外側で二重のケージが逆回転します。
- **D / 黒とゴースト**：反射しない黒い面、またはTEV 2段で8×8走査線を乗算するゴースト。クロームとの対比に使います。

2で「トーラス＋ケージ付き八面体＋スパイク」「3連ジャイロ」「八面体＋スパイク衛星」「スパイク中心の混成」「ボクセル文字＋ジャイロ＋ケージ」の5編成を切り替えます。文字は `.+` / HYPER / VOID。形状は剛体で、八面体の頂点のみ打撃で放射状に伸びます。アンカーの位置交換はイージングします。

背景は24単位間隔の連続した長い格子梁。192単位の描画範囲でX/Y/Zすべてを循環させ、視点から60〜84単位で黒へ減衰するため、再配置される遠端は見えません。主役周囲20単位は梁の該当区間だけを切り取り、20〜32単位で徐々に立ち上げます。セル丸ごとの突然の消去、重複する端面、遠景の高周波ゴースト模様は撤去。通常時は背景の移動とUVを60Hz、主役の姿勢は20fpsのまま更新します。A中は背景も8tickのチャージ動作に従います。

カメラは `guLookAt` と球面オービットを使用。打撃ごとに主役0→1→2→重心の注視を切り替え、注視点は係数0.42で先に動き、方位・仰角・ロールは最短角度差を使う `vel = vel*0.55 + delta*0.16` のスプリングで追従します。バンクと打撃由来のロール目標、およびburstは0.86で減衰し、余韻を残します。十字キーでバンクし、微細なリサージュの呼吸を加えます。距離は基準FOV80度・基準距離16から `k = 16*tan(80°/2)` を作り、常に `radius = k/tan(FOV/2)` で逆算。フレーミング用の距離補正は使いません。保存されるのは注視点の奥行きでの投影倍率で、別の奥行きにある衛星や長いスパイクは広角・個別注視時に画面端を横切る場合があります。

- ギア0〜3の巡航速度は3／12／36／72 unit/sec。十字キー長押しで1→5倍ブースト、離すと指数減衰で復帰。
- 進行軌道はStraight／Spiral／Grid／Whip。Gridは6tickごとに一軸のみ、最大24単位のステップ。
- 60Hz固定物理、通常3tickごとの20fps姿勢更新。インパルスは600×強度、毎tick0.85の減衰。
- Aは2秒でtensionが0→1。8tickごとに描画姿勢を更新し、FOV80→38度・アンカー圧縮・頂点グリッド吸着。高チャージで微振動と背景UVの高速流動。解放で1.2〜4倍の打撃、FOV125度・overdrive最大、その後収束。
- burst>0.5またはtension>0.3で3D画面をEFBに取得し、赤・青を逆方向へずらして緑と再合成。アルファ残像を使わず、UIを巻き込みません。
- 開閉イージング付きの2D反転図形・文字と、四隅のVEL／GEAR／FOV／SEED／TNS計器を維持。TNSは0.7を超えると点滅します。
- 任意のシェイクは校正済みGForceの |g|−1>0.65gで2.5倍打撃。10tickクールダウンと0.3g未満への復帰で再検出します。

## ビルド・検証

Docker Desktopを起動してから：

```powershell
./scripts/build.ps1
./scripts/check-render.ps1
```

buildはassertテスト（4段ギア、ブーストの立ち上がりと復帰、overdrive、4種の軌道とGridの単軸制約、Aの8tick更新・2秒チャージ・単発解放と強度差、安全なフォント参照・5種類の構造巡回、主役とワールド進行の分離、3軸モジュロ周期、指定バネ係数・最短角度・オーバーシュートと収束、nyプロファイルの黒白帯・単一反射リング、注視追従・ドリーズーム・連打時のリグ安定性、頂点吸着、マスクの開閉、目標追従、シェイク、フレームレート独立性、連打・復帰）を実行してWii向けにビルドします。

check-renderは別バイナリと `.dolphin-check` でギア・軌道・方向入力・Aのホールドと解放・Bの文字マスク6種を自動切替。キーやフォーカス操作なしで26枚を `artifacts/render-*.png` に保存し、黒・白・高彩度色の存在と画像の変化を検査します。通常版に自動操作は入りません。 `./scripts/check-render.ps1 -Lattice` は背景だけを3軸へ連続移動させ、64枚の連続画像を保存し、背景の消失と大きな占有率ジャンプを検査します。ユニットテストでは再配置の前後が完全な黒になること、ワールド座標の巻き戻し前後で格子集合が一致すること、ミップマップの平均色とバッファ境界を検証します。

WiiではSDカードの `apps/geezy` に `boot.dol` と `meta.xml` をコピーしてHomebrew Channelから起動します。実機性能・実リモコンのシェイク感度・出力変換器は未確認。映像モードは本体設定に従います。長時間停止後の物理追従は0.25秒までです。

Makefileは[devkitPro公式Wiiサンプル](https://github.com/devkitPro/wii-examples/tree/master/graphics/gx/triangle)がベース。描画と加速度入力は[libogc](https://github.com/devkitPro/libogc)を使用しています。
