# Geezy

Wii Homebrew用のVJビデオシンセ。0.5は、黒い空間にリキッドメタルの構造物を浮かべ、低速ドリフトと入力時の疾走を演奏する試作です。音同期は行いません。

## 起動・操作

```powershell
./scripts/run.ps1
```

既定のDolphinは `D:\Dolphin-x64\Dolphin.exe`。別の場所なら `-Dolphin 'パス'`。実行ファイルは `apps/geezy/boot.dol`。専用プロファイル `.dolphin-prototype` を使用します。初回の画面設定はウィンドウに引き伸ばす設定です。既存のGFX.iniは上書きしません。

Wiiリモコンは十字キーが左になる横持ち。センサーバー不要。Dolphinでは映像ウィンドウにフォーカスを置いて操作してください。

| 操作 | Wiiリモコン | Dolphinキーボード |
| --- | --- | --- |
| 打撃・高速貫通・カメラの高速イージング | Aを押す | A |
| 6fps・低速ドリフト | Aを長押し | Aを長押し |
| 打撃＋領域反転。長押しでマスクを維持 | B | B |
| パレット再生成＋反射帯の周波数切替＋打撃 | 1 | 1 |
| リング／巨大十字柱／スパイク／リボンを切替 | 2 | 2 |
| X/Y方向を変更して斜め前方へ突進、残像をねじる | 横持ちの十字キー | 矢印キー |
| 55度望遠／105度広角へイージング | ＋／− | E／Q |
| 復帰：物理・色・カメラ・残像を初期化 | ＋と−を同時押し | R |
| 特大打撃（通常の2.5倍） | シェイク | Dolphinの加速度エミュレーション設定から |
| 終了 | HOME | H |

平常時は12 unit/secで漂い、Aで600 unit/secのインパルスを加えます。長押し中は基礎速度2 unit/sec・6fps。Bで動く反転マスクと控えめな背景残像、2で空間切替、Rで復帰します。シェイクは通常の2.5倍の打撃です。

## 描画と運動

- Clear Colorと複数のパレット帯はRGB(0,0,0)、ハイライトはRGB(255,255,255)。色帯は最小成分0・最大成分255へ正規化。黒は意図した描画色です。
- 64×64共有環境マップは4／6／8階調。1で周波数2.5→6.0→12.0→2.5と巡回。REPEAT・最近傍補間で描画します。
- 背景は漆黒。ドームのセルの87.5%を描画せず、残りも細いワイヤーだけにします。構造物と破片が黒背景から浮かび上がる構成です。
- 分断するスリット残像とカメラ直前の巨大面は削除。EFB残像はB押下中または描画用burstが0.4を超える時のみ、Zテスト無効で前景の奥へ約3%拡大・微回転・約19%の明るさで描画します。平常時は残しません。
- 60Hz固定物理。基礎巡航12／slow時2 unit/sec、基礎回転0.35／0.08 rad/sec。自動インパルスとUVジャンプは廃止し、UVも低速で流します。
- 打撃は速度に600×強度を加算し、移動・回転・変形のインパルスを毎tick0.85倍に減衰。カメラ座標や描画値を瞬間移動させません。
- FOV55〜105度、ロール、投影中心（±0.35以内）の目標値へ毎tick0.28の指数イージング。ロールは最短の回転方向を使います。＋／−も目標FOVだけを変えます。
- 描画用の状態は通常3tickごとの20fps、A長押し中10tickごとの6fpsで更新。イージング途中の姿勢を段階的に表示します。
- シェイクはlibogcの校正済みGForceを使用。正常な加速度レポートで |g|−1 が0.65gを超えると2.5倍の打撃。10物理tick（約167ms）のクールダウンと、0.3g未満への復帰による再検出を行います。
- 96単位のカメラ基準モジュロで4空間と192枚の破片を循環配置。FOV・ロール・投影中心は目標値へイージングします。
- 3Dの後に `GX_LO_INV` による領域反転。ブラインドは縦スクロール、チェッカーは斜め移動、十字はカメラと逆向きの回転＋burstに応じた太さ変更、三角形は拡大・回転しながら横切ります。

## ビルド・検証

Docker Desktopを起動してから：

```powershell
./scripts/build.ps1
./scripts/check-render.ps1
```

buildは低速ドリフト、自動バーストの不在、20／6fpsサンプリング、打撃直後の座標不変、目標追従と最短角度、0.85の減衰、シェイクの強度・閾値・クールダウン・再検出、フレームレート独立性、モジュロ境界、連打、周波数巡回と復帰のassertテストを実行してビルドします。

check-renderは別バイナリと `.dolphin-check` で4空間・打撃・合成加速度によるシェイク・低速巡航・反転を自動切替。キーやフォーカス操作を行わず、ウィンドウ単独の16枚の画像を `artifacts/render-*.png` へ保存します。黒・白・高彩度色の存在と画像の変化を検査します。アクセント時の暗い残像には中間色を許容し、黒を失敗扱いにはしません。通常版に自動操作は入りません。

WiiではSDカードの `apps/geezy` に `boot.dol` と `meta.xml` をコピーしてHomebrew Channelから起動します。実機性能・実リモコンのシェイク感度・出力変換器は未確認。映像モードは本体設定に従います。長時間停止後の物理追従は0.25秒までです。

Makefileは[devkitPro公式Wiiサンプル](https://github.com/devkitPro/wii-examples/tree/master/graphics/gx/triangle)がベース。描画と加速度入力は[libogc](https://github.com/devkitPro/libogc)を使用しています。
