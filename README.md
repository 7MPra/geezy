# Geezy

Wii Homebrew用のVJビデオシンセ。0.12.0は、ボタンだけで漆黒の浮遊空間から全画面の極彩色まで演奏する試作です。音同期は行いません。

## 起動・操作

```powershell
./scripts/run.ps1
```

既定のDolphinは `D:\Dolphin-x64\Dolphin.exe`。別の場所なら `-Dolphin 'パス'`。実行ファイルは `apps/geezy/boot.dol`。専用プロファイル `.dolphin-prototype` を使用します。初回の画面設定はウィンドウに引き伸ばす設定です。既存のGFX.iniは上書きしません。

Wiiリモコンは十字キーが左になる横持ち。センサーバー不要。Dolphinでは映像ウィンドウにフォーカスを置いて操作してください。

| 操作 | Wiiリモコン | Dolphinキーボード |
| --- | --- | --- |
| 2秒チャージ＋空間圧縮＋加速ストロボ、離すと1.2〜4倍の打撃 | Aを長押し→離す | A |
| トレイル増幅＋開閉する反転マスク（押すたび次の図形） | B | B |
| HUDの表示／非表示 | 1＋PLUS | 1＋E |
| 反射色切替＋打撃（離した時に確定） | 1を押して離す | 1 |
| 主役の編成と進行軌道を同時切替＋打撃（離した時に確定） | 2を押して離す | 2 |
| タップで方向転換＋打撃、長押しで5倍ブースト＋視線をずらす | 横持ちの十字キー | 矢印キー |
| 主役から大きく視線を外す（離すと復帰） | B＋十字キー | B＋矢印キー |
| 速度・密度の4段ギアを上げる／下げる | ＋／− | E／Q |
| 復帰：物理・色・カメラ・チャージを初期化 | ＋と−を同時押し | R |
| 特大打撃（任意・通常の2.5倍） | シェイク | Dolphinの加速度エミュレーション設定から |
| 終了 | HOME | H |

最初はギア1。−で静かなギア0、＋を2回押すと最大のギア3です。十字キーを短く押して方向を打ち込み、長押しで加速。Aで空間を引っ掛け、離して解放。Bを押すとギアに関係なく残像が強まり、反転グラフィックが立ち上がり、離すと収束します。シェイクなしで全操作が完結します。

## コマンドで見た目を組み合わせる

方向は横持ちした時の上下左右。Dolphinでは数字キー・A/Bと矢印キーの組み合わせです。1・2の単押しは離した時に確定し、コマンドに使った場合は単押しの色／編成変更を発火しません。コマンドを押しっぱなしにしても連打されません。

| 同時押し | ↑ | → | ↓ | ← |
| --- | --- | --- | --- | --- |
| **1＋方向：主役の質感** | クローム | 発光グリッド | 走査線ゴースト | ワイヤー＋頂点ドット |
| **2＋方向：主役の配置** | 非対称トリニティ | 巨大1体・オフセンター | 絡み合う2体 | 中心1体＋小型衛星群 |
| **1＋2＋方向：背景** | 格子＋トンネル | 太い多角形ワープトンネル＋小ポリゴン | 全画面ドーム＋格子 | 小ポリゴンの3Dマトリクス |

梁の形は **1＋2＋斜め方向** で直接選択します。「梁＋トンネル」の組み合わせとして呼び出します。ドームと組み合わせる場合は、その後1＋2＋↓を押します。方向を離しても選択は維持されます。

| 1＋2＋方向 | 梁の形 |
| --- | --- |
| ↖ | 3軸の立体格子 |
| ↗ | 奥へ続く矩形ゲート（横梁＋縦柱） |
| ↘ | 奥へ伸びる平行ブレード（幅広・薄い断面） |
| ↙ | 3方向の斜材トラス |

| 同時押し | 動作 |
| --- | --- |
| **A＋1** | 反射模様をホライゾン→4階調→オイルスリック→白黒へ巡回 |
| **A＋2** | 主役の生成バンクだけを5種類で巡回（進行軌道を維持） |
| **B＋1** | Bを保持したまま1で図形を追加送り（ブラインド／チェッカー／十字／三角形／同心角枠／放射ウェッジ） |
| **B＋2** | 進行軌道だけをStraight→Spiral→Grid→Whipへ巡回（主役を維持） |
| **1＋2を押し、両方離す** | リミックス：編成・配置・質感・背景・梁の形・反射・軌道・図形・色をまとめて組み直す |

例えば「1＋→で発光グリッド」「2＋↓で2体構成」「1＋2＋←で粒子マトリクス」を順番に打ち込み、Aを溜めながら2で編成を入れ替え、離してドロップできます。各設定は次のコマンドまで保持され、リミックスも速度ギアを維持します。反射模様はクローム／ゴーストで見え、グリッドとワイヤーは専用の色表現を使います。

A/Bはコマンド中もチャージ／アクセントとして動作します。Aを先に押して1や2を叩けば、溜めを継続したまま切り替えられます。1・2を使う方向コマンド中は操舵とブーストを抑制し、B＋方向の視線外しと区別します。斜め方向は1＋2との組み合わせで梁の形を選び、1のみ／2のみでは設定を選びません。複数の指定が重なった場合は「方向コマンド→Bの組み合わせ→Aの組み合わせ」の順に優先します。1＋2に方向を加えるとリミックス予約は取り消されます。

四隅のUIに現在の設定番号を表示：S＝編成、L＝配置、M＝質感、V＝軌道、BG＝背景、T＝梁の形、R＝反射、X＝反転図形（いずれも0始まり）。2D反転マスクは図形だけです。1＋PLUSで計器を隠せます（1を先に押すか同時押し。先にPLUS単体を押すと通常のギア操作も発火します）。＋と−の同時押しで全設定を初期化できます。

## 描画と運動

主役と背景を別の座標系で描きます。主役は配置モードに応じたローカルアンカーに常駐し、進行座標 `world_cam` は背景だけを移動させます。方向を変えて走り続けても主役は遠方へ流されません。

- **A / クローム**：128×128、LINEAR、CLAMP。曲率補正したnyの−0.28〜0未満は漆黒、0〜0.14は純白。上側は白→ネオン→天頂の黒へ滑らかに移り、下側は−0.65付近の1本だけが別色相で反射します。トーラスは頂点の滑らかな法線を回転・ビュー変換し、環境マップを引きます。TEVは1段、ディザなし。ホライゾン設定では1を4回押すごとに虹色のオイルスリックになります。
- **B / グリッド**：64×64＋1×1までのミップマップ、トライリニア＋4倍異方性フィルタ、REPEAT。黒い面の縁と中央線だけが発光し、UVが一方向へ流れます。
- **C / ケージ**：テクスチャを使わない純白またはシアンの線と頂点ドット。八面体の外側で二重のケージが逆回転します。
- **D / 黒とゴースト**：反射しない黒い面、またはTEV 2段で8×8走査線を乗算するゴースト。クロームとの対比に使います。

1でシードを更新し、2で5つの生成バンクを巡回。シード×バンク×オブジェクト番号から、ジャイロトーラス／ケージ付き八面体／星型スパイク／二重角フレームに加え、以下の5系統を混在させます。巻き数・断面・枚数などの組み合わせが変化し、テストで512シード中400通り以上の異なるレシピを確認します。

- トーラス結び目：巻き数(2,3)／(3,4)／(3,5)／(2,5)、閉じたチューブの滑らかな法線。
- スライス彫刻：球状／立方体状／八面体状の8〜12枚の板。打撃と位相で交互に分離・合体。
- 多軸機構：3〜5重のリングと欠けた円弧、4／8／12角断面。
- 3Dタイポ：HYPER／VOID／.+／01／ERR／WII／シード由来の記号列を厚いボクセルに変換。
- スーパー式多面体：対称軸数と鋭さが変わる彫刻に、非対称な八面体突起を組み合わせ。

配置は3体・巨大1体・2体・中心1体＋3〜5衛星。注視点も実際の主役数へ対応します。WIREスキンでは全造形を線と頂点ドットだけで描き、面描画をassertで禁止しています。

背景の梁は立体格子・連続ゲート・平行ブレード・斜材トラスの4種。24単位の周期で配置し、ゲートはX/Y軸、ブレードはZ軸に梁を絞り、トラスはセル内にXY/YZ/XZ方向の斜材を置きます。192単位の描画範囲でX/Y/Zすべてを循環させ、視点から60〜84単位で黒へ減衰するため、再配置される遠端は見えません。主役周囲20単位は梁の該当区間だけを切り取り、20〜32単位で徐々に立ち上げます。セル丸ごとの突然の消去、重複する端面、遠景の高周波ゴースト模様は撤去。通常時は背景の移動とUVを60Hz、主役の姿勢は20fpsのまま更新します。A中は背景も8tickのチャージ動作に従います。

小ポリゴン192個をリング状に配置したトンネル層を格子に重ねます。各片はワールドに固定され、3軸とも96単位で循環。視点から32〜44単位で消え切ってから再配置し、主役の周囲12〜18単位も減衰させます。実際の移動方向へ片を伸ばし、加速時に長くなる軌跡で進行ベクトルを見せます。

背景1では24段の太い六角／八角／12角フレームが進行軸に沿って迫ります。進行距離192単位で循環し、72〜92単位で消えてから再配置するため、端で突然出現しません。ギア3または背景2では、カメラを全方位に包む半径約150の内向き多面体ドームを描画。クローム／グリッド／黒パネルで背景を覆い、視線を外しても未描画の穴を作りません。

カメラは `guLookAt` と球面オービットを使用。打撃ごとに主役0→1→2→重心の注視を切り替え、注視点は係数0.42で先に動き、方位・仰角・ロールは最短角度差を使う `vel = vel*0.55 + delta*0.16` のスプリングで追従します。バンクと打撃由来のロール目標、およびburstは0.86で減衰し、余韻を残します。十字キーでバンクし、画面方向へ視線をずらします。B＋十字キーでは大きく狙いを外せます。オービット中心と実際の注視先を分離しているため、主役を画面外へ送るパンが可能。離すと視線は主役へ戻ります。微細なリサージュの呼吸を加えます。距離は基準FOV80度・基準距離16から `k = 16*tan(80°/2)` を作り、常に `radius = k/tan(FOV/2)` で逆算。フレーミング用の距離補正は使いません。中央注視時に保存されるのは注視点の奥行きでの投影倍率です。視線外し中は意図的に構図を崩します。別の奥行きにある衛星や長いスパイクは広角・個別注視時に画面端を横切る場合があります。

- ギア0〜3の巡航速度は3／12／36／72 unit/sec。十字キー長押しで1→5倍ブースト、離すと指数減衰で復帰。主役の基礎回転も巡航速度×ブーストに連動し、打撃の回転インパルスを加算します。角度の循環周期は各回転軸の速度比に合わせ、折り返しによる姿勢ジャンプを防ぎます。
- 進行軌道はStraight／Spiral／Grid／Whip。Gridは6tickごとに一軸のみ、最大24単位のステップ。
- 60Hz固定物理、通常3tickごとの20fps姿勢更新。インパルスは600×強度、毎tick0.85の減衰。
- Aは2秒でtensionが0→1。8tickごとに描画姿勢を更新し、FOV80→38度・アンカー圧縮・頂点グリッド吸着。高チャージで微振動と背景UVの高速流動。加えて6→5→4→3→2tick周期のストロボが加速し、背景の黒白と3D面・線の白黒を逆位相にします（最大30Hz、姿勢サンプリングとは独立）。解放で1.2〜4倍の打撃、FOV125度・overdrive最大、その後収束。
- burst>0.5またはtension>0.3で3D画面をEFBに取得し、赤・青を逆方向へずらして緑と再合成。アルファ残像を使わず、UIを巻き込みません。
- RGB色収差とは別のEFBバッファで再帰トレイルを保存。背景描画後・主役描画前に1.02〜1.06倍拡大＋微回転し、TEVでRGB各成分から24を引いて0にクランプした後、ギアとoverdriveに応じて加算します。黒に一定色を足すことはなく、履歴だけなら完全な黒へ消え切ります。保存は反転マスクとHUDの前。チャージ中はトレイルを消去し、白いストロボが解放後まで残ることを防ぎます。
- 市松模様は2マスを1周期として巻き戻し、画面外2列分も描画。整数tickでスクロールを計算し、X/Y合わせて600tick（10秒）で同じ位相へ戻るため、途中で白黒が入れ替わる継ぎ目や端の欠落がありません。
- 開閉イージング付きの2D反転図形（ブラインド・チェッカー・十字・三角形・同心角枠・放射ウェッジ）はBを押している間だけ開き、離すと閉じます。打撃・色変更・方向転換はマスクを発火しません。四隅のVEL／GEAR／FOV／SEED／TNS計器は1＋PLUSで表示切替。TNSは0.7を超えると点滅します。
- 任意のシェイクは校正済みGForceの |g|−1>0.65gで2.5倍打撃。10tickクールダウンと0.3g未満への復帰で再検出します。

## ビルド・検証

Docker Desktopを起動してから：

```powershell
./scripts/build.ps1
./scripts/check-render.ps1
```

buildはB限定マスク・HUDトグル・ストロボ周期・512シードの造形レシピ・結び目の閉曲線と法線・トンネル端のフェード、および単押しと同時押しの分離・順序違い・押しっぱなしでの多重発火防止・256回のリミックスとリセット、およびassertテスト（4段ギア、ブーストの立ち上がりと復帰、overdrive、4種の軌道とGridの単軸制約、Aの8tick更新・2秒チャージ・単発解放と強度差、安全なフォント参照・5種類の構造巡回、主役とワールド進行の分離、3軸モジュロ周期、指定バネ係数・最短角度・オーバーシュートと収束、nyプロファイルの黒白帯・単一反射リング、注視追従・ドリーズーム・連打時のリグ安定性、頂点吸着、マスクの開閉、目標追従、シェイク、フレームレート独立性、連打・復帰）を実行してWii向けにビルドします。

check-renderは別バイナリと `.dolphin-check` でギア・軌道・方向入力・Aのホールドと解放・質感／配置／背景の方向コマンド・反射模様4種・図形マスク6種・B＋方向の視線外しを自動切替。キーやフォーカス操作なしで26枚を `artifacts/render-*.png` に保存し、黒・白・高彩度色の存在と画像の変化を検査します。通常版に自動操作は入りません。 `./scripts/check-render.ps1 -Lattice -Beams 0` は背景だけを3軸へ連続移動させ、64枚の連続画像を `artifacts/lattice-0-*.png` に保存し、背景の消失と大きな占有率ジャンプを検査します。`-Beams 1`／`2`／`3` で各梁の形を検査できます。`./scripts/check-render.ps1 -Checker` は市松マスクだけを96枚連続撮影し、画面の白黒占有率が常に約50%で動き続けることを検査します。数値テストでは巻き戻しの前後もスクロール量が一定で、600tick周期が一致することを確認します。ユニットテストでは回転の加減速・角度折り返しの連続性・視線外しと復帰・小ポリゴンの3軸周期も検査します。再配置の前後が完全な黒になること、ワールド座標の巻き戻し前後で格子集合が一致すること、ミップマップの平均色とバッファ境界を検証します。

`./scripts/check-render.ps1 -Sculptures` は9系統×4スキンを自動巡回し、4つの配置・ドーム・太いトンネル・チャージ・Bマスクも確認します。`-Trail` は白い矩形からの再帰残像を単独描画し、完全な黒への消滅を画像で検査します。

WiiではSDカードの `apps/geezy` に `boot.dol` と `meta.xml` をコピーしてHomebrew Channelから起動します。実機性能・実リモコンのシェイク感度・出力変換器は未確認。映像モードは本体設定に従います。長時間停止後の物理追従は0.25秒までです。

Makefileは[devkitPro公式Wiiサンプル](https://github.com/devkitPro/wii-examples/tree/master/graphics/gx/triangle)がベース。描画と加速度入力は[libogc](https://github.com/devkitPro/libogc)を使用しています。
